# GreenBody V50 working baseline

V50 is an unfinished, verifiable geometry baseline, SHA-256
`956774764f7d7ef18a3d832a8409612e64a14371da98d3987b7ec77fc6576449`.

It adds a bounded 3.5% X-only central waist/low-abdomen cross-section expansion
to V49. Arms, legs, rig, weights, poses, cameras, material, lights and scoring
remain unchanged; each relative shape key receives the same rest-space field.

Its v4 fixed-protocol scores are front 81.90913, side 85.05250, back 81.86342,
mean 82.94168 and minimum 81.86342. This improves every view over V49. The
5% waist study is retained as rejected evidence because it regresses all V50
aggregates. Structural validation, fresh driver validation and real squat and
push-up renders/reports pass. V50 is not 99 or runtime/animation approval.
