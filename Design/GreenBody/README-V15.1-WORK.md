# V15.1 — 平滑上臂轮廓，当前工作版本

文件：`GreenBody-v15.1-work.blend`，SHA256 `4d757e22f2356bbf38142062bf93e4dfb7ae5a240a360f10260fc5f3d88db841`。精确复制自 `calibration/multiview-reference-v3/captures/V15-smooth-arm/canonical.blend`。旧 V12、V14、V15 中间快照保留。

在 V14 基础上，按静态上臂骨轴、蒙皮区域与平滑包络，微调两侧上臂截面外移，最大16mm；不改骨架、权重、相机或姿态协议。最终包络为 `sin²(π(t−0.04)/0.81)`，在骨段参数0.04和0.85处位移与一阶导数都归零，避免短过渡造成的肩部台阶。这是网格肌肉轮廓修改，不是移动图片或骨骼关节标注。

所有 Basis/修正形态键同步移动，保留 V14 的相对增量与双侧姿态驱动。不要只改基础 mesh 而遗漏形态键。构建器：`scripts/build_green_body_v15.py --mode translate-smooth --amount .016`，源为 V14 工作文件，输出须为新路径。
