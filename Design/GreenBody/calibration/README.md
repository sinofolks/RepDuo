# GreenBody 校准评分系统

用于反复比较 **真实 Blender 渲染与指定参考视角**。本工具不会修改原始 `.blend`，不会将参考图片贴到模型上，也不会把指数称为“还原百分比”。

## 打开结果

直接打开 `report.html`，无需联网或启动服务。选择模型记录后，可拖动叠图透明度，切换真实渲染、参考、轮廓差异和关键点；下方查看分项、左右区域、历史及来源校验。

当前正式开发基线采用 `reference-v3.json` → `references/v3/`。这是**标注修订号**，与模型 V1/V2 无关。`references/v1/`、`v2/` 和相应早期评分保留作审计；不同协议的分数不直接比较。

## 一条命令评估新模型

在 RepDuo 工程根目录运行（Python 3.10+，依赖见 requirements.txt）：

```sh
python3 Design/GreenBody/calibration/calibrate.py run \
  --blend /绝对路径/GreenBody-v3.blend --label V3
```

流程为：载入独立 Blender 后台进程 → 固定摄影棚 → 真实彩色渲染及独立几何遮罩 → 关键点投影 → 评分 → 保存不可覆盖的新记录 → 更新本地报告。

默认 Blender 路径 `/Applications/Blender.app/Contents/MacOS/Blender`，可用 `--blender` 指定。源模型需要与当前底模兼容的 `GreenBody` 网格和骨骼命名。新输出目录带时间戳；采集器拒绝覆盖非空目录；源模型在采集前后校验一致。

默认是 **几何＋姿态 / 固定外观**：相机、灯光和材质均固定。它用于改形，不能检验你刚修改的原生材质。优化材质时加 `--native-appearance`，保留模型材质、仍统一相机灯光；这会形成另一组协议历史，不与固定材质成绩混比。

## 怎么评分

所有误差都在 480×800 的规范画布测量，人物高 720 px。仅按完整人物包围盒做**统一缩放和平移**，记录变换；不旋转、不镜像、不横向拉伸，不为每个候选搜索“最好看的对齐”。因此画面占比和全局平移被消除，而相机朝向、透视和姿态仍会影响指数。

| 指标 | 默认权重 | 定义 |
|---|---:|---|
| 轮廓重合 | 30 | 前景交集 / 并集（IoU）×100 |
| 边界对齐 | 20 | 双向边界 F1；固定容差为人物高度 0.5%，即 3.6 px |
| 分区宽度 | 20 | 七个固定高度带，分别比较左右外轮廓距离与行内占用宽度 |
| 关节点位置 | 15 | 12 个关节中心投影与参考估计点的距离；扣除参考标注容差 |
| 颜色 | 10 | 重叠前景区域 Lab 均色与分位数分布差异 |
| 明暗 | 5 | 前景内粗尺度 L* 空间对比度差异；不含背景，不重复计全局亮度 |

误差项使用 `100 × exp(-误差 / 固定尺度)`，不是统计概率。宽度尺度 18 px、关节点尺度 36 px、Lab 差异尺度 20、明暗尺度 10；这些是**本项目工程权重和容差**，没有用人工满意度数据训练或认证。所有参数、算法文件及参考数据都进入评分协议指纹，修改后必须重评基线。

头、肩、躯干、髋、大腿、小腿、脚是**高度带名称，不是人体语义分割**；手臂可能落入躯干高度带。分区会保留左右误差，不能只看整体平均。颜色/明暗只衡量最终渲染外观，不证明真实材质或灯光被还原。

## 防止“分数升了，模型却更差”

- 空遮罩、身体触边裁切、未完成采集、输入图被更改会拒绝评分。
- 候选关键点缺失按零分处理，固定参考分母；不删掉难点重新计算高分，不完整记录不进入改善比较。
- 每条记录保存模型、采集图、参考图、遮罩、规则、Blender 构建版本及采集参数校验值。
- 只有相同协议可相减；固定材质模式下材质也必须相同。姿态作为候选的一部分记录，**本轮不是纯网格的独立因果实验**。
- `compare` 检查总分和局部退步：任一高度带下降超过 3 分，会保留复核状态。总分变化须超过 0.25 分及遮罩敏感性幅度，才建议复核新候选；这不是自动验收阈值。
- 参考边缘±1规范像素会重新计算敏感性范围，提醒边界分割对结果的影响；**不是置信区间**，也不涵盖所有误差来源。
- 同一模型做了重复采集；检查像素与评分是否复现，避免把采样噪声当进步。

## 开发迭代闭环

1. 先用固定条件记录基线；确认参考标注与相机朝向。
2. 看轮廓差异、左右分区和关节点，选一个要改的因素。例如只改头型，不同时改相机和曝光。
3. 模型另存新版本，运行 `run`。
4. 比较新旧同协议的 `result.json`：

```sh
python3 Design/GreenBody/calibration/calibrate.py compare \
  /绝对路径/基线/result.json /绝对路径/候选/result.json
```

5. `review_candidate` 仅表示值得人工复核，`hold_for_review` 表示变化太小、敏感或有区域退步。**程序不自动覆盖、批准或部署模型。**
6. 即使站姿分数变高，也必须看侧面、背面、深蹲和俯卧撑，验证体积和关节变形。当前系统尚未给这些视角打分。

要调相机、灯光或评分参数：创建新的采集 profile / 参考配置，并用同一新协议把旧模型和新模型都重新跑一遍。不能只改新模型的条件后沿用旧分。

## 更新参考标注

原图坐标原点在左上，x 向右，y 向下。`reference-v3.json.landmarks` 存原图像素坐标；候选点来自骨骼投影，不是从渲染图猜测。`uncertainty_px` 是人工容差，不是候选可以自行放大的参数。骨骼点在皮肤内部，投影检查不等于遮挡可见性检查。

将配置另存新名字，修正点/容差/ROI，保持真实的 `annotation_status`。仅在实际逐点复核后改为 `reviewed`。使用新目录冻结：

```sh
python3 Design/GreenBody/calibration/calibrate.py init-reference \
  --config /绝对路径/reference-v4.json --out /绝对路径/references/v4
```

新评估加 `--reference /绝对路径/references/v4`。冻结目录不能覆盖，原始图片 SHA 不匹配也会拒绝。当前参考图是 AI 概念图，背面与三维厚度未知；即便单视角指数为 100，也不是全三维 1:1 证明。

## 单独采集 / 重新评分 / 测试

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python-exit-code 1 --python Design/GreenBody/calibration/render_candidate.py -- \
  --blend /绝对路径/模型.blend --out /绝对路径/新采集目录

python3 Design/GreenBody/calibration/calibrate.py evaluate \
  --capture /绝对路径/新采集目录 --label 新模型

python3 Design/GreenBody/calibration/calibrate.py report
python3 -m unittest discover -s Design/GreenBody/calibration -p 'test_*.py' -v
```

`report.html` 是可再生成的当前索引；`captures/` 和 `runs/` 是保留的证据。HTML 不联网，所有图片内嵌，文本安全转义；报告无法实时更改或驱动 Blender。未来可加入受限参数搜索，但本版先提供可信、可重复的评分与回归检查。
