# GreenBody Calibration

<!-- impeccable:product-schema 1 -->

This is a scoped development tool inside RepDuo, not a redesign of the iOS product.

## Platform
web

## Stack
Local Python scoring with a standalone HTML report. User explicitly approved direct implementation of a local overlay tool, model selection, regional error inspection and score history, without a separate mockup or iOS integration (2026-09-13).

## Users
The RepDuo owner and model developer comparing genuine Blender renders with the approved green humanoid concept.

## Product Purpose
Make successive model changes inspectable, reproducible and measurable against a fixed reference, without presenting a heuristic score as a percentage of 3D reconstruction fidelity.

## Capabilities and Constraints
Single standing-view calibration first. Preserve source concept, existing .blend files and iOS code. All measured data must link to captured inputs, settings and algorithm versions. AI concept joint annotations are provisional, not ground truth. Invalid or incomparable runs must not masquerade as progress. No automatic destructive model replacement.
